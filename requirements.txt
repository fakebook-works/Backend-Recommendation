# Direct dependencies are pinned to exact versions.
#
# These previously used wide ranges, most importantly sentence-transformers>=3.4,<6,
# which spans three major versions. Two builds a week apart could therefore ship
# different embedding stacks, and a major bump can change encode/normalise behaviour
# or the on-disk model format without raising an error — the embeddings would simply
# drift, and cosine similarity against previously stored vectors would stop meaning
# what it used to.
#
# The versions below are exactly what the previous ranges resolved to, so pinning them
# changes nothing about what a build produces today; it only stops it moving on its own.
# Regenerate deliberately with:
#   pip install --dry-run --ignore-installed --report resolve.json -r requirements.txt
#
# Transitive dependencies are still unpinned. A fully hash-locked file has to be
# generated on the deployment platform (linux, python 3.11) rather than a workstation,
# because the wheel set differs.
